# [SPECTRA](https://matheuscoletti08.github.io/SPECTRA/)\*\*

> **Um reprodutor de áudio com inspiração na estética dos anos 90.**

O **SPECTRA** é um projeto web que resgata a experiência visual dos clássicos reprodutores de mídia para desktop, combinando elementos inspirados no Windows 9x.

O site permite adicionar e reproduzir músicas através de links do YouTube, organizar faixas em uma playlist e controlar a reprodução por meio de uma interface retrô, com ícones pixelados e visualizador animado.

## Funcionalidades

- Reprodução de músicas através de links do YouTube.
- Adição dinâmica de faixas à playlist.
- Identificação automática do título e canal da música.
- Controles de reprodução: anterior, reproduzir, pausar, parar e próxima.
- Controle de volume.
- Exibição do tempo de reprodução e duração da faixa.
- Visualizador gráfico animado.
- Destaque visual para a faixa selecionada.
- Interface responsiva com estética inspirada no Windows clássico.

## Tecnologias

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização, layout e identidade visual retrô.
- **JavaScript:** lógica de reprodução, gerenciamento da playlist e interações.
- **Canvas API:** renderização gráfica do visualizador animado.
- **YouTube IFrame Player API:** integração e controle da reprodução.
- **YouTube oEmbed API:** obtenção dos metadados das faixas.
